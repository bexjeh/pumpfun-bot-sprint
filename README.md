Filtered-momentum paper-trading bot for the pump.fun replay: it enters on a 15% breakout, but only on liquid coins (at least 20 SOL of real reserves) with volume-backed demand (at least 60% buys and twice as much buy as sell SOL volume over the last 20 trades), with a 0.4 SOL stake and one entry per mint, then exits on take-profit (+35%), a trailing stop (12% below the peak, armed at +15%), a stop-loss (-15%), or a one-hour maximum hold. Fully deterministic — no clock, no environment, no randomness — so two runs produce byte-identical action logs.

## Run it

```sh
node main.ts
```
